# Bevakly v2.53.0 – Vad håller på att hända?

## Nytt
- Ny användarnära Signalradar högst i branschflödet.
- Visar upp till tre viktigaste pågående förändringar.
- Summerar antal signaler som stärkts.
- Identifierar konkurrent att följa extra utifrån flera signalers sammanlagda eskaleringspoäng.
- Varje förändring kan öppnas till en kronologisk beviskedja.
- Visar steg: Första signal, Bekräftas, Formell process, Beslut/tilldelning, Genomförande.
- Visar tydligt att 0–100 är eskaleringsstyrka, inte sannolikhetsprocent.
- Mobil layout för den nya signalradarn.
- Synligt versionsnummer uppdaterat till v2.53.0.

## Begränsning
Signalradarn använder aktuell körnings fusioner/tidslinjer. Persistent cross-run timeline påstås inte vara verifierad.
