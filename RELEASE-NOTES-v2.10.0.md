# Bevakly v2.10.0 – Daily Flow

Fokus: Bevakly ska vara snabb även efter sex månaders daglig användning.

## Nytt
- Lästa händelser sparas per bevakningsprofil i webbläsaren.
- Nytt sedan sist prioriterar nu olästa händelser.
- Öppning av en källa markerar händelsen som läst.
- Varje händelse kan markeras som läst utan att öppnas.
- En hel filtrerad vy kan markeras som läst med ett klick.
- Standardflödet döljer lästa händelser; de kan visas igen.
- När allt är hanterat visas ett tydligt “Du är ikapp”.

## Varför
Målet är att återkommande användare inte ska behöva bearbeta samma information varje morgon. Historik finns kvar men konkurrerar inte med det nya.

## Begränsning
Läst-status är lokal per webbläsare i denna version. Synk mellan enheter kräver senare användarkonto/serverlagring.
