# Bevakly v3.06.0 – Competitor Source Coverage

Fokus: bättre rådata för konkurrentbevakningen.

- Rättar PreZeros fasta svenska nyhetskälla till den nu verifierade `prezero.se/mina-sidor/nyheter/`.
- Inför ett explicit register över verifierade officiella konkurrentkällor för PreZero, Ragn-Sells, Stena Recycling, REMONDIS, Verdis och Ohlssons.
- Skiljer på verifierad nyhetssida, verifierad karriärsida och faktisk källlucka.
- Exponerar källtäckningen i industry-feed-diagnostiken så att en saknad officiell sida inte kan döljas bakom generisk discovery.
- Gissar inte fram nyhets- eller karriär-URL:er för REMONDIS/Ohlssons där separat sida inte verifierats.

Princip: fler riktiga förstahandskällor är bättre än fler antagna källor.
