# Bevakly v2.58.0 – Ask Bevakly

## Nytt
- Ny **Ask Bevakly**-yta högst i branschflödet.
- Frågor rankas mot aktuell Signal Timeline.
- Förstår konkurrentnamn/geografier via textmatchning samt frågor om starkaste signal och expansion.
- Kan svara på vilka lokalt följda förändringar som försvagas.
- Svar visar relevanta förändringar med score, process-steg, riktning och faktamängd.
- Öppningsbart källunderlag med original-länkar.
- Tydliga limitations under varje svar.
- Exempelfrågor för snabb användning.

## Guardrails
- Ask Bevakly använder endast aktuell källgrundad Signal Timeline + browserlokalt följda förändringar.
- Den fyller inte informationsluckor med generell AI-kunskap.
- Signal score beskrivs som beviskedjans styrka, aldrig som sannolikhet.
- Om underlaget inte räcker svarar den att relevant signal saknas.

## Begränsning
Detta är första retrieval-/regelbaserade Ask-versionen. Ingen extern LLM-anropning eller persistent serverhistorik har lagts till.
