# Bevakly v2.14.0 – Lokal radar

- Breddar källnätet från 19 till 31 bevakade ingångar.
- Lägger till 10 regionala SVT-redaktioner för tidiga lokala signaler.
- Lägger till Vafabmiljö och Renova som regionala bolagskällor.
- Utökar lokal relevans med miljötillstånd, miljöprövning, bygglov, markköp, etablering, utsläpp, förbränning och ÅVC/ÅVS-relaterade begrepp.
- Breda lokala nyhetssidor filtreras på branschord innan enskilda artiklar hämtas.
- Egna bolagskällor är faktakällor om den egna verksamheten men ska inte räknas som oberoende mediebekräftelse bara för att publiceringen ligger på Mynewsdesk.
- Permanent UI-version uppdaterad till v2.14.0.
