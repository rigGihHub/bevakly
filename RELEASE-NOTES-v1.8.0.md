# Bevakly v1.8.0 – Bevakningsprofiler

- Flera parallella bevakningsprofiler per användare.
- Varje profil har namn, bransch, huvudmarknad, geografier, aktörer och teman.
- Skapa, redigera, växla och ta bort profiler direkt från dashboarden.
- Separat Morning Brief per profil.
- Separat personlig relevansinlärning per profil.
- Profilfokus påverkar urval och ranking; kritiska skyddade signaler kan fortfarande visas utanför fokus.
- Profiler lagras lokalt i webbläsaren i denna version.

Produktgränsen mot Anbudify är oförändrad: profilerna gäller strategisk omvärldsbevakning, inte upphandlingsarbete.
