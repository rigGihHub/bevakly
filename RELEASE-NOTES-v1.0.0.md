# Bevakly v1.0.0

## Nytt
- Contract Radar: uppskattar bevakningsfönster för nästa sannolika konkurrensutsättning.
- Tar hänsyn till upphandlingar, tilldelnings-/avtalssignaler, explicit avtalslängd när den kan utläsas och historik upp till sex år.
- Varje fönster visar underlag, antaganden, säkerhet och konkreta verifieringssteg.
- Tydlig spärr: ett uppskattat fönster presenteras aldrig som verifierat upphandlingsdatum.

## Viktig begränsning
För säkra prognoser behöver Bevakly senare lagra strukturerade TED-fält som contract-conclusion-date, contract-duration-start-date-lot och contract-duration-end-date-lot. v1.0 använder tills vidare främst historiska händelser/rubriker och konservativa antaganden.
