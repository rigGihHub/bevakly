# Real News Golden Set v2.80.0

Versionslåst manuell benchmark med 20 verkliga svenska avfalls-/återvinningssidor verifierade 2026-09-07.

## Omfattning
- konkreta kommunala insamlingsuppdrag
- konkurrentavtal
- stora investeringar och ny behandlingskapacitet
- prisjusteringar
- regeländringar
- policy/opinion som inte ska konkurrera med faktiska marknadshändelser
- evergreen/reference material
- indexsidor
- gamla artiklar som återupptäcks senare

Varje fixture innehåller URL, publiceringsdatum, observerat datum, manuell relevans/tier, freshness och provenance. Artikeltexten är kort parafraserad testdata, inte kopierad fulltext.

## Resultat efter v2.80-kalibrering
- 20/20 pass
- precision 1.000
- recall 1.000
- false positives 0
- false negatives 0
- article validation accuracy 1.000
- freshness accuracy 1.000
- provenance accuracy 1.000
- tier-floor accuracy 1.000

Detta är ett litet manuellt golden set och får inte beskrivas som produktionsprecision. Det ska växa över tid med svåra verkliga fel som observeras i liveflödet.
