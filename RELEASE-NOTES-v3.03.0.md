# Bevakly v3.03.0 – Competitor Signal Lanes

Focus: broaden competitor coverage without diluting general industry news.

- Adds a dedicated rotating competitor signal queue across procurement, permits, local media and corporate change.
- Keeps the existing one-query-per-actor news lane intact.
- Uses a daily deterministic rotation so the same competitor is not searched through the same lens every run.
- Reserves broad industry discovery slots so competitor focus does not starve general market coverage.
- All new hits still pass existing quality, freshness, provenance, dedupe and evidence rules.
