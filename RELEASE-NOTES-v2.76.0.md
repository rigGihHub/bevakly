# Bevakly v2.76.0 – Bid News Relevance Calibration

## Fokus
Rätt nyhet för en Bid Manager, inte bara tekniskt relevant branschnyhet.

## Prioriterade teman
1. Kontrakt / tilldelning
2. Anläggning / kapacitet
3. Tillstånd / reglering
4. Etablering / mark
5. Förvärv / M&A
6. Investering
7. Pris / kostnad / materialflöde
8. Konkurrentförflyttning

Ledning, teknik/pilot och generell hållbarhet kan vara relevanta men får inte automatiskt gå före konkreta kommersiella eller regulatoriska förändringar.

## Tier
- A – Direkt affärskritisk
- B – Strategiskt viktig
- C – Relevant omvärld
- D – Perifer

Score-justering:
- A +8
- B +4
- C 0
- D -12

Kommunikations-/event-/utmärkelse-lika rubriker får dessutom relevansstraff.

## Guardrail
Relevansrankningen mäter arbetsvärde för marknads-/anbudsbevakning. Den är inte sannolikhet, fakta-confidence eller bevis för framtida utfall.
